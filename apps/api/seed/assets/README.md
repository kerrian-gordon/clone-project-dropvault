# Demo seed assets

`flower.mp4` is the [MDN CC0 sample video](https://interactive-examples.mdn.mozilla.net/media/cc0-videos/flower.mp4). It is used as the playable content for `Demo-video.mp4`. The seed script adds an MP4 `free` box to reach the metadata fixture's listed size.

`q4-deck.pptx` is a sample slide created for Dropvault with PptxGenJS. The seed script adds an unreferenced XML part to reach the metadata fixture's listed size. The PDF and TXT samples are generated by the seed script.
